# Roadmap

Forward-looking planning docs for Fallout Chat Mod. These are **not** committed product
commitments — they capture researched options, feasibility, and risk so we can pick what
to ship next.

| Doc | Summary |
| --- | ------- |
| [fan-site-integrations.md](./fan-site-integrations.md) | Researched options for pulling FO76 data from community fan sites & wikis (builds, nuke codes, server status, item/price data). |

## Status legend

- ✅ **Shipped** — live in production
- 🟡 **Planned** — agreed, not yet built
- 🔵 **Candidate** — researched, feasible, not yet scheduled
- 🔴 **Parked** — investigated, deprioritized (no API / high risk / low value)
