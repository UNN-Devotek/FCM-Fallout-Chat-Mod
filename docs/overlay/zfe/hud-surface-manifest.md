# FCM HUD surface manifest

This maps repository-owned surfaces of the optional HUD mod. The desktop overlay is separate.
FCM-generated SWFs/BA2s are project artifacts; Bethesda HUDMenu exports, extender DLLs, and
credential containers are user-owned inputs and must not be committed or redistributed.

and no HUDMenu. Its backend/desktop integration and local acceptance status are documented in
[background bridge](background-server-bridge.md).

## Provider contract

Discovery walks already-exposed movie/parent/stage/root objects, never DLLs/files/ports.

| Provider | Gate | Call shape |
| --- | --- | --- |
| xScal chat | Required chatInterface methods; optional runtime info must validate when present; priority over ZFE if both exist | Objects for payload methods; no arguments for designated runtime/state/reset methods |
| ZFE chat | Positive native-chat runtime/capability response on the selected dispatcher | `call(verb, jsonString)` |
| Generic callback | Separately identified; never a fallback for xScal chat verbs | Logging or numeric `Input.*`; xScal requires Boolean input results |

See [provider guide](modder-guide.md) for public-versus-compatibility input APIs and
[FCM integration](native-chat-relay/fcm-integration.md) for relay permissions and controls.

## User-owned runtime state

The player installs their chosen extender using its author's instructions. Extender configuration,
logs, and credentials belong to that install; FCM must not guess provider token filenames or edit
credentials through settings storage. ZFE's documented legacy reset fallback uses
`Data/ZFE/chat-auth.bin` only when the supported reset command is unavailable and the user follows
the recovery instructions. Do not apply that path to xScal by analogy.

`Fallout76Custom.ini` and `Data/hudmodloader.ini` are merged, never replaced wholesale. Native
ZFE global overrides win over fragment keys. xScal uses its own `[Chat]` section. Confirm actual
runtime endpoint and loaded artifact after restart rather than relying on package filenames.

The legacy `game-mods/FCMBridge/build.sh` requires an exact fresh vanilla HUDMenu SHA-256 and
FFDec-compatible toolchain; it also contains game-install steps. It is not the modern widget
build command. Its vanilla recompilation must be verified for that specific game revision.
