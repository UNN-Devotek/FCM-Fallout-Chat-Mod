FCM HUD CUSTOMIZATION
=====================

Open F11 -> FCM -> Customize. These settings affect your HUD, not other users.

Customize groups controls into Position, Panel size, Text and input, Appearance,
Auto-hide, and Colors submenus to avoid the old oversized menu.
FCM keeps its visible menu columns inside the frame, independently of chat position.
On very small frames an oversized column is reduced to fit.

ULTRAWIDE POSITION
- Position -> Move left/right can pass the centered 1920x1080 frame edges.
- INI x accepts -960 through (2880-width); for example x=-330. Vertical
  bounds remain 0 through (1080-height). No automatic monitor detection.
- Move only as far as your visible screen allows. Position -> Reset position
  restores x=10/y=10 without changing size, colors or other preferences.
- The host/game determines visible edges; native ultrawide validation is pending.

SIZE AND POSITION
- Panel width +/- and height +/- are independent. Move up/down/left/right.
- Input height +/- and input text size +/- adjust the actual editor displayed
  over the widget, including the ZFE/SharedHUDTools editor.
- Input width and alignment always follow the widget input area. They are not
  separate settings. The input remains inside the panel with fixed padding.
- Feed text size +/- is independent of input text size.
- Small panels constrain effective input dimensions to leave room for chat.

OPACITY AND COLORS
- Opacity +/- controls background opacity, including tab and input boxes.
- Colors... lets you choose panel background, tab box, input box, border,
  message text, input text, default name text, active/inactive tab text, and
  hint text colors. Pick a color from the submenu.
- Default name text affects names without a server-provided color. It does
  not replace a user's chosen name color.
- Color theme cycles the existing basic themes; individual colors can then
  be changed separately. Reset all settings restores the packaged defaults.

AUTO-HIDE
- Auto-hide ON/OFF is independent of the remembered hide delay.
- Hide delay +/- changes the delay by five seconds, from 1 to 600 seconds.
- Changing the delay while OFF does not turn auto-hide on.
- OFF cancels the timer and reveals the panel. Manual Hide still works.

EXACT VALUES IN Data/FCMChat.ini
Edit keys in the existing [FCMChat] section; do not add duplicate keys/sections.

width=600
height=300
fontSize=16
inputHeight=48
inputFontSize=24
bgAlpha=0.85
bgColor=#0A0907
tabRowColor=#080705
inputBgColor=#080705
borderColor=#F5CB5B
textColor=#FAF4DA
inputTextColor=#F5CB5B
senderColor=#F5CB5B
tabActiveColor=#F5CB5B
tabInactiveColor=#B49544
promptColor=#AC9043
autoHideEnabled=false
autoHideSec=60

Input height accepts 28-120; input font size accepts 8-47, or 0 to use existing
provider sizing. Background opacity accepts 0-1. Colors accept #RRGGBB.
Input height alone does not enlarge the font. The row grows to fit larger text.
Legacy autoHideSec=0 also disables auto-hide; enabling it supplies 60 seconds.

Manual /hide, F11 Hide chat, and the hide key stay hidden until the Open Chat key
is pressed in an allowed HUD mode. New messages still wake inactivity auto-hide,
but not manual hide. Escape or leaving a menu does not undo manual hide.
For existing INIs, append InspectMode,ExamineConfirmMode,MessageMode to
hideInHUDModes to suppress item inspection, examine/scrap confirmation, and
modal-message HUD modes; preserve the rest of your list. The supplied INI includes
all three. Sticky manual hide requires the updated widget BA2, not just the INI edit.
Actual scrap/confirmation mode transitions require native testing.

PUBLIC-EVENT AUTO-BROADCAST (INI only, default OFF)
autoBroadcastWorldEvents=true enables announcing public events; the default
false never subscribes and pays no cost. broadcastEventsMode=allow (default)
announces ONLY the listed names; =deny announces everything EXCEPT the listed
names. Names are comma-separated, case-insensitive, EXACT matches only (never
substrings). A blank allow-list reads as broadcast OFF. Default allow-list:
Scorched Earth, Neurological Warfare, A Colossal Problem, Seismic Activity,
Encryptid, Eviction Notice, Moonshine Jamboree.

SAVING AND RELOADING
F11 changes apply immediately. ZFE saves appearance in vendor-scoped
FCMChatWidget/settings.ini. Saved appearance takes priority over Data/FCMChat.ini, but environment
settings (`linkUrl`, all keybinds, and `hideInHUDModes`) always come from the active file.
If you already customized with F11, use F11 for further changes, or update the
corresponding saved settings through your extender's storage location before
reloading. xScal 0.2.17+ saves appearance locally in its named
fcmchatwidget-layout-v1 document; those values also take priority over the INI.
Older xScal builds use the permission-gated relay layout fallback. Changes are
session-local if persistence is unavailable. Restart Fallout 76 after changing
Data/FCMChat.ini, a BA2, or extender configuration.

FIXED FEATURES
Badges, channel tags (including their colors and visibility), emojis, default
channel, and available channels are not appearance settings. Older showChannelTag,
channelTagColor and colorGeneral/Trading/Events/Infests/Raids/Server overrides are
ignored. You can still switch channels normally. There are no input-width or
input-alignment settings.
OPEN-CHAT KEY (ZFE)
-------------------
The shipped ZFE values are Insert in both locations. To use another supported key, change
`Data/FCMChat.ini`; the widget synchronizes ZFE's active watcher after discovery:

  Data/FCMChat.ini
  [FCMChat]
  openKey=DELETE

The extender config still supplies its startup default before the widget loads. See KEYBINDS.txt
for accepted values, precedence, conflicts, and the separate xScal limitations.

For xScal, do not add OpenChatKey to xscal.ini. Change FCMChat.ini openKey; the widget maps
it to xScal's physical Input.* polling API and retains the named-action fallback. See KEYBINDS.txt
and the xScal Input interface article: https://www.nexusmods.com/fallout76/articles/268.

SCROLL KEYBINDS
---------------
The modern FCMChatWidget reads these navigation keys from the same [FCMChat] section. The
shipped values are explicit, including the two intentional blank defaults:

  channelNextKey=NextPage
  channelPrevKey=PrevPage

  scrollUpKey=Up
  scrollDownKey=Down
  scrollBottomKey=
  activateLinkKey=F8
  hideKey=DELETE

Up/Down are the packaged arrow-scroll bindings; their ArrowUp/ArrowDown, Cursor, and Dpad
spellings are treated as aliases. Set either direction to a forwarded HUD action (for example
Console) or a physical xScal/ZFE token (for example F12) to rebind it. An empty value disables
that direction. `activateLinkKey` opens a selected link directly in the operating system browser
through GFx only during an OpenChat-owned edit and defaults to Enter; it is inert while chat is
closed and does not require the desktop overlay. `scrollBottomKey` is intentionally blank by
default, so Home and End remain game controls until one is explicitly selected. The F11 **Scroll to newest** menu action is
always available. Feed keys are consumed only while the open-chat key owns the visible input
session. The default `hideKey=DELETE` hides only while idle; a blank value disables the keyboard
hide binding while keeping `/hide` and the F11 **Hide chat** menu action available. See
KEYBINDS.txt for provider-specific action names and physical-key behavior.
