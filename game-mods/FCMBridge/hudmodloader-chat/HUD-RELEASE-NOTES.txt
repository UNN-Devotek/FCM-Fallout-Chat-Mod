FCM HUD 2.10.134
==============

Windows xScal text input
------------------------
Added a working SharedHUDTools text-entry option for Windows xScal users whose
native Input.BeginInput reports input_unavailable. Set xscalInputMode=shared in
Data/FCMChat.ini, then restart Fallout 76. This uses HUDModLoader's keyboard
editor and ControlMap lock. Native input remains the default for installations
where it works; shared mode does not support controller text entry.

HUD commands
------------
Type /help for the private general command guide. Event and staff command
lists are separate: /event help lists all 33 event names and shortcuts, and
/mod help lists moderator actions. Help appears in your own chat feed, scrolls
away with new messages, and can be traversed line by line with Up and Down
while the editor is open. If the game consumes a leading slash, type help or
event help without it.

Use an event shortcut such as /sbq from General to announce the event in the
Events feed and its mapped Discord channel. The backend checks whether the
event is enabled and applies its channel rule, cooldown, and template. Your
command result is private to your HUD.

The HUD now accepts giveaway start, list, last, join, leave, and stop commands.
Type /giveaway alone for private help. Giveaway cards and winner announcements
appear in the channel where the giveaway started and its mapped Discord
channel. Joining shows a private confirmation; creators receive a private
message when they try to enter their own giveaway.

Choose only the ZFE or xScal install folder for your extender.

Updating
--------
Exit Fallout 76 before updating. Existing users replace only
Data/FCMChatWidget.ba2 and keep their edited INIs, HUDModLoader registry,
archive list, and saved account data. New users should follow the selected
provider folder's INSTALL.txt. The xScal DLL, desktop overlay, and optional
background Server Bridge are separate downloads.
