FCM HUD 2.10.153 DEV test candidate
==============

Staff moderation
----------------
For linked moderators and admins. /mod durations now accept 30, 30m, 2h, 1d or
1w (up to 30 days). A ban needs a duration or the word perm; a ban without
one, or with 0, is refused instead of becoming permanent. Mute without a
duration lasts 10 minutes. Server-tab players can be muted, kicked and banned
by name or [#S0000000] reference, and a player who posted in both General and
Server is no longer reported as two matches. Server messages cannot be
deleted. Unban and unmute accept an exact account name when the player has no
visible message. Errors now say what happened, for example that staff cannot
be moderated from the HUD. Messages deleted from the dashboard, Discord or
another HUD disappear from this HUD too. Requires the matching backend update;
native game acceptance remains pending. Staff on older HUD versions must update
to issue permanent bans: the server now refuses a ban without an explicit
duration or perm, and older versions send neither.

Dev integration and stationary names
-----------------------------------
Includes the latest Dev flood-cooldown retry handling together with the blue-name
stability work from 2.10.150. An already admitted visible name can remain blue
while its exact identity, eligibility and private presence remain current.
Hiding, recycling, renaming, becoming ineligible or losing private presence
retires that association. Expired observations cannot acquire it again.
This is a DEV testing build; native stability acceptance remains pending.

Blue FCM names
--------------
Existing overhead names can turn blue for nearby FCM users in your confirmed
Server room. Nonusers keep normal colors; hostile/wanted colors and vanilla
nameplate visibility remain authoritative. Set blueNameplates=false in
Data/FCMChat.ini to disable it. The renderer is shared with Server Bridge 0.2.10.
Requires the matching backend update. This is a testing candidate for the next
update; native acceptance and public publication are pending.

Channel navigation and sends
-----------------------------
Type g, t, e, i, r, or s alone and press Enter to select General, Trading, Events,
Infests, Raids, or Server without sending a message. Prefix a message with /t, /i,
/e, or another channel command to send there without changing your current tab.
For example, /t looking for plans sends to Trading while you stay on General.
A prefix without a message neither switches tabs nor sends. Plain messages target
the selected tab. Dot forms and full-name aliases work too. No setting is required.
Server selection and sending require a confirmed current Server chat session;
unavailable Server messages are never sent to a community channel instead.
The packaged keybind guide and website guide document the same channel mapping.
This is a local test candidate; native game acceptance remains pending.

xScal appearance and keybinds
-----------------------------
On xScal 0.2.17+, F11 appearance now saves through xScal's named local storage,
including when xScal does not forward the relay's layout-save permission.
Changing openKey in Data/FCMChat.ini releases the old Insert action after a
game restart. Use openKey=PERIOD if another mod uses Insert. Escape closes
the editor; the configured hide key (Delete by default) hides the idle HUD.
ZFE's vendor storage and default Insert path remain unchanged.

Windows xScal text input
------------------------
Added a working SharedHUDTools text-entry option for Windows xScal users whose
native Input.BeginInput reports input_unavailable. Set xscalInputMode=shared in
Data/FCMChat.ini, then restart Fallout 76. This uses HUDModLoader's keyboard
editor and ControlMap lock. Native input remains the default for installations
where it works; shared mode does not support controller text entry.

HUD commands
------------
Type /help for the private general command guide. Event and staff command
lists are separate: /event help lists all 33 event names and shortcuts, and
/mod help lists moderator actions. Help appears in your own chat feed, scrolls
away with new messages, and can be traversed line by line with Up and Down
while the editor is open. If the game consumes a leading slash, type help or
event help without it.

Use an event shortcut such as /sbq from General to announce the event in the
Events feed and its mapped Discord channel. The backend checks whether the
event is enabled and applies its channel rule, cooldown, and template. Your
command result is private to your HUD.

The HUD now accepts giveaway start, list, last, join, leave, and stop commands.
Type /giveaway alone for private help. Giveaway cards and winner announcements
appear in the channel where the giveaway started and its mapped Discord
channel. Joining shows a private confirmation; creators receive a private
message when they try to enter their own giveaway.

Choose only the ZFE or xScal install folder for your extender.

Updating
--------
Exit Fallout 76 before updating. Existing users replace only
Data/FCMChatWidget.ba2 and keep their edited INIs, HUDModLoader registry,
archive list, and saved account data. New users should follow the selected
provider folder's INSTALL.txt. The xScal DLL, desktop overlay, and optional
background Server Bridge are separate downloads.
