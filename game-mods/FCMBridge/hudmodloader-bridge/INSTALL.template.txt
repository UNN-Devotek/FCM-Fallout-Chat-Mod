FCM Server Bridge {version}

This optional invisible HUDModLoader child exports game HUD roster observations
to Fallout Chat Mod on this computer. Sign into Fallout Chat Mod only. The
bridge has no separate login or pairing code.

PREREQUISITES
HUDModLoader plus exactly one extender: the latest ZFE or the latest xScal.
These are separate downloads. Do not install the visible FCM HUD or the old
FCMBridge with this Server Bridge. Fallout Chat Mod does not install it for you.

CHOOSE ONE INSTALL PATH (FALLOUT 76 MUST BE CLOSED)

ZFE INSTALL
-----------
1. Install HUDModLoader and the latest ZFE. A normal ZFE install may contain
   only dxgi.dll at first; its feature-specific Data folders may not exist.
2. Back up the files below, then copy Data/FCMServerBridge.ba2 into the game's
   Data directory.
3. Add FCMServerBridge once to Data/hudmodloader.ini. Preserve every existing
   entry; FCMServerBridge.hudmodloader.ini is a snippet, not a replacement.
4. Append FCMServerBridge.ba2 once to [Archive] sResourceArchive2List in the
   active Fallout76Custom.ini. Preserve HUDModLoader.ba2 and unrelated archives.
5. Do not install falloutchatmod.ini, a TextChat fragment, or zfe.ini for the
   bridge. If an old FCMServerBridge TextChat fragment exists, back up and
   remove only that fragment.
6. Remove xScal if it is installed. Start Fallout Chat Mod and sign in at
   https://{host}, launch Fallout 76, and enter a public world. The overlay
   exposes Server automatically after fresh exports are confirmed.

XSCAL INSTALL
-------------
1. Install HUDModLoader and the latest xScal.
2. Do not edit xscal.ini for the Server Bridge. The [Chat] enabled and
   relayEndpoint settings are only for the visible FCM in-game HUD, not this
   invisible bridge.
3. Back up the files below, then copy Data/FCMServerBridge.ba2 into the game's
   Data directory.
4. Add FCMServerBridge once to Data/hudmodloader.ini. Preserve every existing
   entry; FCMServerBridge.hudmodloader.ini is a snippet, not a replacement.
5. Append FCMServerBridge.ba2 once to [Archive] sResourceArchive2List in the
   active Fallout76Custom.ini. Preserve HUDModLoader.ba2 and unrelated archives.
6. Do not install ZFE or create ZFE folders or configuration files.
7. Start Fallout Chat Mod and sign in at https://{host}, launch Fallout 76,
   and enter a public world. The overlay exposes Server automatically after
   fresh exports are confirmed.

Fallout76Custom.ini is normally in Documents/My Games/Fallout 76 on Windows
(including redirected Documents) or the matching Proton prefix directory.

This BA2 is configured for https://{host}. Do not create or edit its exported
JSON file manually.
ZFE may use its documented Documents or LocalAppData fallback storage root.
The desktop reads only known export files, asynchronously, and never writes
game files. Steam Windows/Linux-Proton are the current native test targets;
Game Pass is not yet certified.

STATUS / CHAT
The bridge is input-silent: it registers no HUDModLoader menu, hotkey, editor,
or HUDMod::UserEvent listener. Provider/export status is written only through
the scoped export and privacy-safe provider logs. Exporting is NOT proof of
backend room confirmation. Server appears in the overlay only after authenticated
backend confirmation. Party remains a separate overlay feature.

HUD users and bridge-plus-overlay users share the SAME Server room, history and
message IDs when mutual roster evidence establishes the same world, irrespective
of ZFE/xScal or Discord/display names. Missing or one-sided observations can delay
discovery. No authoritative world ID is available; unrelated rooms must not be
merged to conceal this limitation.

Same-world fast travel retains the generation while evidence remains valid.
World hopping, main menu, account change, logout, game exit, missing heartbeat
or expired observations remove stale membership. Five-second heartbeats do not
refresh the thirty-second observation limit. Old files alone cannot activate
Server: the overlay requires advancing fresh snapshots after attaching.
Test builds and the public service use separate files.

TROUBLESHOOTING
- No export: check archive path, loader registry and active custom INI precedence.
- Provider conflict: remove either ZFE or xScal; exactly one may be installed.
- Scoped storage required: update the selected official extender; the bridge
  does not fall back to native chat or a separate login.
- Storage unavailable: check provider-supported storage permissions. Export
  failures are retried at most once per second.
- Fresh roster unavailable: inspect fixed Menu/Roster/source diagnostics. Do
  not share roster JSON, account names or private identifiers in bug reports.
- Exporting but no Server: confirm overlay build/environment/auth, game
  detection and advancing export age. Do not edit JSON to force room assignment.
- Different devices: each overlay accepts only its own local game export and
  authenticated session; another device's native link cannot grant access.

UPDATE / REMOVE
With the game closed, replace only the BA2 with the tested same-environment
candidate. To remove, remove only FCMServerBridge from the loader registry and
FCMServerBridge.ba2 from the archive list, then remove that BA2. Keep backups,
unrelated mods, shared configs and native HUD credentials.

Ruffle/automated checks are required before packaging/installing, but do not
prove native storage timing or game stability. This build requires fresh
two-client native acceptance on both extenders before being called verified.
