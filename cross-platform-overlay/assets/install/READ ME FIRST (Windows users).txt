>>> WINDOWS USERS - READ THIS <<<

The Windows installer is NOT in this download. Get it from the official site
(it's the exact same build, and it's clean):

    https://falloutchatmod.com        (then:  SYSTEM  ->  INSTALL)

VirusTotal scan (always points to the current build):

    https://falloutchatmod.com/virustotal

Why isn't the Windows installer on Nexus? Nexus's automated system quarantines
installer .exe files by default. It's a false positive (0 / 72 on VirusTotal),
and we're getting it sorted out with Nexus support. Until then, grab the Windows
version from the site above.
