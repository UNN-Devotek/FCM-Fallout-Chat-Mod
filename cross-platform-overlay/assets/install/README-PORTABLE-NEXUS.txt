Fallout Chat Mod - Windows portable
===================================

1. Extract the complete ZIP to a normal writable folder.
2. Run "Fallout Chat Mod Portable <version>.exe" from that folder.
3. Keep the executable beside its FCMData folder when moving or updating it.
4. Sign in with Steam or Discord and complete onboarding.
5. Run Fallout 76 in Borderless Windowed mode.

The portable overlay does not require installation and does not modify Fallout 76.
Its account data, settings, logs, keybinds, and window state remain in FCMData.

Optional Server chat bridge
---------------------------
The Optional FCM Bridge folder contains FCMServerBridge 0.2.6 and manual setup
instructions. It is not required and is never installed automatically. Install it
only if you want current-server chat in the desktop overlay.

Do not install FCMServerBridge together with the visible FCMChatWidget HUD or the
legacy FCMBridge. Exit Fallout 76 before changing any game files and follow exactly
one provider section in Optional FCM Bridge/INSTALL.txt: ZFE or xScal.

Update
------
Download the newer portable package from this mod's Nexus Files tab. Preserve the
existing FCMData folder and replace the application files around it.
