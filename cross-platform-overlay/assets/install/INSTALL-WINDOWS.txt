Fallout Chat Mod — Windows install
====================================

1. Double-click "Fallout Chat Mod Setup <version>.exe" (in this folder).
2. The installer is per-user — no administrator prompt. It installs to:
     %LocalAppData%\Programs\Fallout Chat Mod\
3. Launch "Fallout Chat Mod" from the Start Menu (or the desktop shortcut).
4. Sign in with Discord and finish the short onboarding (enter your Fallout 76
   name when asked).

Using the overlay
-----------------
- Run Fallout 76 in BORDERLESS WINDOWED mode (not exclusive fullscreen) — no
  overlay can draw above exclusive fullscreen.
- The overlay shows automatically while Fallout 76 is running.
- Updating: new versions are NOT automatic. When you see the in-app "Update
  available" notification, download the latest from Nexus Mods
  (https://www.nexusmods.com/fallout76/mods/4082) or falloutchatmod.com and run
  the installer again, or use the CLI one-liner in PowerShell:
     irm https://falloutchatmod.com/install.ps1 | iex
  Your settings, keybinds and Discord link are preserved, and it works even if
  you are several versions behind.

Uninstall
---------
Settings -> Apps -> Installed apps -> Fallout Chat Mod -> Uninstall
(or run the Uninstall entry in the install folder).
