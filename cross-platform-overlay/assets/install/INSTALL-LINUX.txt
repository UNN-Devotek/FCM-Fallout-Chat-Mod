Fallout Chat Mod — Linux install
==================================

1. Extract this zip. You'll have:
     Fallout Chat Mod-<version>.AppImage   (the app — portable, runs anywhere)
     Fallout Chat Mod-<version>.deb         (Debian/Ubuntu apt package — optional)
     INSTALL-LINUX.txt                      (this file)
     fallout-chatmod-keepabove.kwinrule     (KDE-only, see below)
2. Make the AppImage executable:
     chmod +x "Fallout Chat Mod-<version>.AppImage"
   (Or: right-click -> Properties -> Permissions -> "Allow executing as
   program".)
3. Run it:
     ./"Fallout Chat Mod-<version>.AppImage"
4. Sign in with Discord and finish onboarding (enter your Fallout 76 name).

Debian / Ubuntu (.deb) — alternative to the AppImage
----------------------------------------------------
Prefer an apt-managed install? Use the bundled .deb instead of the AppImage:
     sudo apt install "./Fallout Chat Mod-<version>.deb"
   (or:  sudo dpkg -i "Fallout Chat Mod-<version>.deb")
Then launch "Fallout Chat Mod" from your application menu.
To UPDATE later, install the newer release's .deb the same way — dpkg upgrades
the package in place (works even if you are several versions behind).

Requirements
------------
- A desktop environment with an X11 or XWayland session.
- libfuse2 (libfuse.so.2) for the AppImage to mount. Most distros have it, but
  FEDORA ships only fuse3 by default, so the AppImage may "launch once, then the
  shortcut does nothing". Two fixes:
     * Recommended on Fedora/Debian/Ubuntu: use the .deb above (no FUSE needed).
     * Or install libfuse2 (Fedora: sudo dnf install fuse-libs; Debian/Ubuntu:
       sudo apt install libfuse2), or run with --appimage-extract-and-run:
          ./"Fallout Chat Mod-<version>.AppImage" --appimage-extract-and-run

AppImageLauncher users — IMPORTANT
----------------------------------
If you have AppImageLauncher, do NOT use its "Integrate AppImage and run" prompt
for this app. It moves the AppImage and creates its own shortcut, which can leave
a launcher that works once and then won't reopen (you'd have to remove and re-add
the AppImage every time). Just run the AppImage directly, or use the .deb. If a
shortcut has already broken this way, remove the AppImageLauncher integration for
"Fallout Chat Mod" and run the AppImage (or install the .deb) instead.

Using the overlay
-----------------
- The overlay shows automatically while Fallout 76 is running (detected under
  Proton). With the game closed it stays hidden by design.
- Updating: new versions are NOT automatic. When you see the in-app "Update
  available" notification, download the latest from Nexus Mods
  (https://www.nexusmods.com/fallout76/mods/4082) or falloutchatmod.com and
  re-run the installer (CLI one-liner, the AppImage installer, or the .deb).
  Your settings, keybinds and Discord link are preserved, and it works even if
  you are several versions behind.

KDE Plasma (Wayland) — automatic, just run Borderless
-----------------------------------------------------
On KDE+Wayland the overlay sets itself up on first launch — there is normally
NOTHING to do. It forces the XWayland backend and installs one KWin window rule
("keep above games") so it stays above Fallout 76 even while the game is
focused, but only while FO76 runs AND the overlay is on the SAME monitor.
Removed automatically on FO76 exit or a monitor change (on another monitor
the overlay behaves as an ordinary window). The rule combines two properties
on the overlay window:

  - keeps the overlay window on top, AND
  - forces the OVERLAY into KWin's Overlay layer, so it stays visible even
    while the game is focused fullscreen. The game is NOT demoted — FO76
    keeps its normal fullscreen stacking (above the panel).

Just run Fallout 76 in BORDERLESS WINDOWED (in-game: Settings -> Display ->
Window Mode = Borderless). Loading screens and the in-game (Scaleform) UI work
normally with these rules.

Optional: install kdotool (Arch/CachyOS: paru -S kdotool [AUR]; Fedora:
sudo dnf install kdotool) so the overlay releases its hotkeys (Insert/Delete/
Home...) when you tab to another app while the game runs. xdotool also works,
but it cannot see native-Wayland windows (keys may stay captured in Konsole/
Firefox). On a plain X11 session, xdotool alone now gives the same hide-on-alt-tab
/ hotkey-release behavior (kdotool is a KDE-Wayland tool). Without either tool,
hotkeys stay held for the whole game session.

If the overlay ever ends up BEHIND the game (e.g. the automatic setup couldn't
run), import the bundled rule by hand:

  1. System Settings -> Window Management -> Window Rules -> Import...
  2. Select fallout-chatmod-keepabove.kwinrule (next to this file)
  3. Apply, then: qdbus org.kde.KWin /KWin reconfigure   (or log out / in)

Uninstalling removes this KWin rule and restores FO76's fullscreen stacking.

In-game cursor lock (Wayland) — explicit, on-demand step
------------------------------------------------------------
On Wayland the compositor drops Fallout 76's mouse-lock while the overlay sits
on top. Fallout Chat Mod never modifies the FO76 Proton/Wine prefix
automatically (not during install, not on launch) -- this is a step you apply
yourself, on your command. The overlay detects this automatically after you
exit FO76 and prompts once via a system notification, so you don't have to
remember to check the tray menu proactively.
  Easiest: open the overlay's tray menu -> "Fix in-game cursor lock
  (Wayland)". Quit Fallout 76 first, then click it; it runs the same
  protontricks commands below and shows the result.

  Manual (community-standard method), if you'd rather run it yourself:
  1. Recommended: run FO76 on the latest Proton 11.x in Steam (Properties ->
     Compatibility -> Force the use of a specific Steam Play compatibility
     tool), or a well-maintained build like Proton-CachyOS or GE-Proton.
  2. Install protontricks: pacman -S protontricks (Arch/CachyOS) / dnf
     install protontricks (Fedora) / pipx install protontricks (Debian/Ubuntu).
  3. Run:  protontricks 1151340 grabfullscreen=y
     (GUI equivalent: protontricks 1151340 winecfg -> Input tab -> tick
      "Automatically capture the mouse in full-screen windows".)
  4. For Borderless-Windowed too, also run:
     protontricks 1151340 -c 'wine reg add "HKCU\Software\Wine\X11 Driver" /v GrabPointer /t REG_SZ /d Y /f && wineserver -w'
  5. Launch Fallout 76 (Fullscreen or Borderless-Windowed).
X11 sessions don't need this.

Do NOT run the game inside gamescope for overlay purposes — its nested
compositor isolates the game and no external overlay can draw over it. In
particular, the launch flags "-f" (fullscreen) and "--force-grab-cursor" make
gamescope grab the keyboard/mouse at the evdev level (below X11), so the
overlay's global hotkeys (Insert/Delete/Home/PgUp/PgDn) AND window dragging stop
working the moment you are in-game. If you must use gamescope, remove
"--force-grab-cursor" and run borderless/windowed instead of "-f". The overlay
log will print an "[input-grab] gamescope ... detected" line when this is the cause.
